Case Study 02 · Professional Work

E-commerce Storefront UX

Interface and storefront improvements carried out while working as a Software Analyst, combining business requirements with frontend implementation.

RoleSoftware Analyst
FocusUI · UX · Business Needs
StackShopify Liquid · HTML · CSS · JS
OutcomeImproved storefront functionality and UX

01 — Problem

For YumJunction, the goal was to create a simple food-discovery and ordering experience that works across different screen sizes while keeping the interface engaging.

02 — Approach

  • Built responsive layouts for different viewport sizes.
  • Created interactive pages using HTML, CSS and JavaScript.
  • Included a user feedback survey to learn from the experience.
  • Focused on page performance and cross-device usability.

03 — What I learned

Good product experiences require more than visual polish: responsive behavior, clear interactions, feedback and performance all influence how users experience a product.

04 — Design direction

The interface prioritizes clear hierarchy, readable content, straightforward calls to action and a layout that adapts naturally across devices.

01 — Context

In my Software Analyst role, I work with e-commerce storefronts and translate business requirements into technical interface changes.

02 — Approach

  • Customized Shopify themes using Liquid, HTML, CSS and JavaScript.
  • Considered business requirements while implementing storefront changes.
  • Worked on functionality and user-experience improvements.
  • Balanced implementation constraints with the intended customer journey.

03 — What I learned

Product design decisions become stronger when user experience, business goals and technical feasibility are considered together.

04 — Scope

This case study intentionally presents the work at a high level and focuses on the design and problem-solving approach rather than exposing internal company information.
